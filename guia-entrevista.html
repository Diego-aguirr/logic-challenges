Formato del test (confirmado por instructivo)

Todo sacado del instructivo oficial que adjuntó Paola:

La dinámica real del test:

1. Elegís el lenguaje (JS, Python, Java, etc.)
2. Ves la consigna con la función a implementar
3. Escribís tu código en el editor
4. Presionás "Evaluar con IA" para validar
5. Si está mal, podés "Reiniciar código" e intentar de nuevo
6. Tenés hasta 10 intentos para corregir
7. Cuando estés conforme o se acabe el tiempo, presionás "Siguiente"
⚠ CAMBIO IMPORTANTE: No es "escribir y listo". Tenés feedback de la IA y hasta 10 intentos para corregir. Esto es MEJOR de lo que pensaba — podés iterar hasta que funcione.

Restricciones reales:

  • 10 minutos para toda la sección de código
  • NO salir de pantalla completa — se monitorea
  • NO mover el cursor fuera del recuadro del examen
  • NO copiar/pegar (Ctrl+C / Ctrl+V) — invalida la prueba
  • Cámara y micrófono activos durante todo el test
  • Se sugiere hacerlo desde computadora (no celular)

Lo que podés hacer:

  • Usar el editor de código de la plataforma
  • Elegir el lenguaje que prefieras
  • Evaluar tu código con la IA (hasta 10 veces)
  • Reiniciar y corregir tu solución
Estrategia con 10 intentos: Si tu primera solución no pasa la validación, analizá qué falla, corregí y volvé a evaluar. Tenés margen para iterar. No busques la solución perfecta de una — escribí algo que funcione, evaluá, y refiná.

CRÍTICO Procesamiento de Strings

Recorrer un string

// Por cada carácter
for (let char of "hola") {
  console.log(char); // h, o, l, a
}

// Con índice
for (let i = 0; i < str.length; i++) {
  console.log(i, str[i]);
}

Verificar si contiene algo

str.includes("a")        // true/false
str.indexOf("a") !== -1  // true/false (más compatible)
str.startsWith("h")      // true/false
str.endsWith("o")        // true/false

Convertir / normalizar

str.toLowerCase()     // "HOLA" → "hola"
str.toUpperCase()     // "hola" → "HOLA"
str.trim()            // " hola " → "hola"
str.split(",")        // "a,b,c" → ["a","b","c"]

Reemplazar

str.replace("a", "x")      // solo la primera
str.replaceAll("a", "x")    // todas las ocurrencias
str.replace(/a/gi, "x")     // con regex (g=todas, i=sin caso)

Extraer porciones

str.slice(1, 3)      // desde índice 1 hasta 3 (no incluye 3)
str.substring(1, 3)  // similar, pero no acepta negativos
str[0]               // primer carácter
Patrón frecuente: Para contar algo en un string, recorré con for...of y acumulá en un contador.

IMPORTANTE Estructuras de Datos (Objetos)

Acceder y verificar

obj.key           // acceso directo

obj?.key          // optional chaining (si obj es null/undefined → undefined)

CRÍTICO Lógica Algorítmica

Patrones que salen SIEMPRE

1. Contar con accumulator

function contarMayores(arr, limite) {
  let count = 0;
  for (let item of arr) {
    if (item > limite) count++;
  }
  return count;
}

2. Buscar el máximo/mínimo

// Con reduce
function findMax(arr) {
  return arr.reduce((max, n) => n > max ? n : max, arr[0]);
}

// Con Math
Math.max(...arr)
Math.min(...arr)

3. Invertir algo

// String
str.split("").reverse().join("")

// Array
arr.slice().reverse()  // sin mutar
// o
[...arr].reverse()

4. Verificar condición para TODOS / ALGUNO

arr.every(x => x > 0)   // ¿todos positivos?
arr.some(x => x < 0)    // ¿hay algún negativo?

5. Agrupar / contar ocurrencias

function contarRepeticiones(arr) {
  const freq = {};
  for (let item of arr) {
    freq[item] = (freq[item] || 0) + 1;
  }
  return freq;
}
// [1,1,2,3,3,3] → {1:2, 2:1, 3:3}

6. Índice de un elemento

function buscarIndice(arr, objetivo) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === objetivo) return i;
  }
  return -1;
}

7. Aplanar array anidado

function aplanar(arr) {
  let resultado = [];
  for (let item of arr) {
    if (Array.isArray(item)) {
      resultado = resultado.concat(aplanar(item));
    } else {
      resultado.push(item);
    }
  }
  return resultado;
}

CRÍTICO Casos Borde (Edge Cases)

El correo dice explícitamente que evalúan si manejás casos borde. Siempre pensá en:

CasoCómo manejar
Array/string vacíoif (!arr.length) return []
Un solo elemento¿Funciona con 1?
null / undefinedif (arr == null) return []
Números negativos¿Tu lógica funciona con negativos?
Strings vacíosif (!str) return ""
Valores duplicados¿Los cuenta dos veces?
Números flotantes¿Usás === o ==?
Checklist mental rápido: Antes de entregar, pensá: ¿funciona con vacío? ¿con null? ¿con un elemento? ¿con elementos repetidos?

JS Trucos específicos de JavaScript

Comparaciones que fallan

"" == 0      // true  ⚠
"" === 0     // false ✓
null == undefined  // true

// SIEMPRE usá === para comparar

"5" - 3          // 2 (resta convierte)

// Objeto

// En parámetros de función

Operador ternario

Ejercicio 4: Elemento más frecuente

MEDIO

Recibe un array. Devuelve el elemento que más se repite.

// Firma:
function masFrecuente(arr) {
  // tu código acá
}

// Ejemplos:
// masFrecuente([1,1,2,3,3,3]) → 3
// masFrecuente(["a","b","a"]) → "a"
// masFrecuente([42]) → 42
function masFrecuente(arr) {
  const freq = {};
  let maxCount = 0;
  let result = arr[0];

  for (let item of arr) {
    freq[item] = (freq[item] || 0) + 1;
    if (freq[item] > maxCount) {
      maxCount = freq[item];
      result = item;
    }
  }
  return result;
}

Ejercicio 10: Rotar array

DIFÍCIL

Recibe un array y un número n. Devuelve el array rotado n posiciones a la derecha.

// Firma:
function rotarDerecha(arr, n) {
  // tu código acá
}

// Ejemplos:
// rotarDerecha([1,2,3,4,5], 2) → [4,5,1,2,3]
// rotarDerecha([1,2,3], 5) → [2,3,1]
// rotarDerecha([], 3) → []
function rotarDerecha(arr, n) {
  if (!arr.length) return [];
  const rotaciones = n % arr.length;
  if (rotaciones === 0) return [...arr];
  return [...arr.slice(-rotaciones), ...arr.slice(0, -rotaciones)];
}

Ejercicio 16: Encontrar duplicados

MEDIO

Recibe un array. Devuelve un array con los elementos que aparecen más de una vez.

// Firma:
function encontrarDuplicados(arr) {
  // tu código acá
}

// Ejemplos:
// encontrarDuplicados([1,1,2,3,3,3]) → [1,3]
// encontrarDuplicados([1,2,3]) → []
function encontrarDuplicados(arr) {
  const freq = {};
  const duplicados = [];
  for (let item of arr) {
    freq[item] = (freq[item] || 0) + 1;
  }
  for (let [key, count] of Object.entries(freq)) {
    if (count > 1) duplicados.push(Number(key) || key);
  }
  return duplicados;
}

Ejercicio 18: Mayor diferencia

DIFÍCIL

Recibe un array de números. Devuelve la mayor diferencia entre dos elementos consecutivos.

// Firma:
function mayorDiferencia(arr) {
  // tu código acá
}

// Ejemplos:
// mayorDiferencia([1,5,2,8,3]) → 6 (entre 2 y 8)
// mayorDiferencia([10,1,5]) → 9 (entre 10 y 1)
// mayorDiferencia([1]) → 0
function mayorDiferencia(arr) {
  if (arr.length < 2) return 0;
  let maxDiff = 0;
  for (let i = 0; i < arr.length - 1; i++) {
    const diff = Math.abs(arr[i] - arr[i + 1]);
    if (diff > maxDiff) maxDiff = diff;
  }
  return maxDiff;
}

    pares: nums.filter(n => n % 2 === 0),
    impares: nums.filter(n => n % 2 !== 0)
  };
}

Estrategia con 10 intentos

El instructivo dice que podés presionar "Evaluar con IA" y tenés hasta 10 intentos para corregir. Esto cambia la estrategia:

  1. Intento 1-3: Escribí la solución más directa que se te ocurra. No busques la perfecta — buscá una que compile y retorne algo.
  2. Intento 4-6: Analizá qué falló. ¿Tipo de retorno? ¿Caso borde? Corregí y evaluá de nuevo.
  3. Intento 7-9: Si seguís sin pasar, simplificá. ¿Podés hacer algo más básico que pase al menos los casos del ejemplo?
  4. Intento 10: Último intento. Poné lo que tengas que funcione para el ejemplo principal.
Clave: No pierdas tiempo en el intento 1 buscando la solución perfecta. Escribí algo, evaluá, y usá el feedback para corregir. Tenés 10 chances.
